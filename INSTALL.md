# 📺 TeleTV Player — Инструкция по установке

## 🚀 Быстрый старт

### Вариант 1: Скачать готовый APK (рекомендуется)

1. Перейдите в [Releases](https://github.com/YOUR_USERNAME/teletv-player/releases)
2. Скачайте последний `TeleTV-Player-v*.apk`
3. Установите на Android TV (см. ниже)

### Вариант 2: Скачать из Actions (для тестирования)

1. Перейдите в [Actions](https://github.com/YOUR_USERNAME/teletv-player/actions)
2. Выберите последний workflow run
3. В разделе "Artifacts" скачайте `TeleTV-Player-debug`
4. Распакуйте и установите APK

### Вариант 3: Собрать локально

```bash
# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/teletv-player.git
cd teletv-player

# Запустите скрипт сборки
chmod +x build-android.sh
./build-android.sh

# APK будет в android/app/build/outputs/apk/debug/
```

## 📱 Установка на Android TV

### Метод 1: Через USB-флешку

1. Скачайте APK на компьютер
2. Скопируйте файл на USB-флешку
3. Вставьте флешку в Android TV
4. Откройте файловый менеджер на TV
5. Найдите APK → Нажмите → Установить

### Метод 2: Через ADB (для продвинутых)

```bash
# Включите ADB debugging на TV:
# Настройки → О устройстве → 7 раз нажмите "Build number"
# Настройки → Для разработчиков → ADB debugging → ВКЛ
# Запишите IP адрес TV

# Подключитесь с компьютера
adb connect <IP-адрес-TV>

# Установите APK
adb install TeleTV-Player-v1.1.0.apk
```

### Метод 3: Через браузер на TV

1. Откройте браузер на TV
2. Перейдите по прямой ссылке на APK
3. Скачайте файл
4. Откройте файловый менеджер → Установите

### Метод 4: Через приложение "Send Files to TV"

1. Установите "Send Files to TV" на телефон и TV
2. Отправьте APK с телефона на TV
3. Установите на TV

## ⚙️ Настройка приложения

### 1. Получите API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите с номером телефона
3. Нажмите "Create application"
4. Заполните форму:
   - App title: TeleTV Player
   - Short name: teletv
   - URL: (оставьте пустым)
   - Platform: Other
   - Description: Telegram media player
5. Нажмите "Create application"
6. Скопируйте **App api_id** и **App api_hash**

### 2. Войдите в приложение

1. Откройте TeleTV Player на TV
2. Введите **API ID** (число, например: 12345678)
3. Введите **API Hash** (строка, например: 0123456789abcdef...)
4. Нажмите "Continue"
5. Введите номер телефона в международном формате:
   - Россия: +79991234567
   - США: +12125551234
   - Украина: +380501234567
6. Нажмите "Send Code"
7. Откройте Telegram на телефоне
8. Скопируйте код из сообщения "Login code: 12345"
9. Введите код в приложении на TV
10. Если включена 2FA — введите облачный пароль

### 3. Используйте приложение

- Выберите канал или чат
- Найдите видео или аудио
- Нажмите для воспроизведения
- Создавайте плейлисты
- Наслаждайтесь! 🎉

## 🔧 Решение проблем

### APK не устанавливается

**Проблема:** "Installation blocked" или "Unknown sources"

**Решение:**
1. Настройки TV → Безопасность (или Конфиденциальность)
2. Найдите "Неизвестные источники" или "Install unknown apps"
3. Включите для файлового менеджера или браузера

### Нет видео/аудио в чатах

**Проблема:** Чат пустой или нет медиа

**Решение:**
- Убедитесь что в чате есть медиафайлы
- Попробуйте другой чат
- Проверьте интернет-соединение

### Ошибка подключения

**Проблема:** "Failed to connect" или "Invalid API"

**Решение:**
- Проверьте правильность API ID и Hash
- Убедитесь что приложение создано на my.telegram.org
- Проверьте интернет-соединение
- Попробуйте перезапустить приложение

### Видео не воспроизводится

**Проблема:** Чёрный экран или ошибка

**Решение:**
- Проверьте формат видео (поддерживаются MKV, MP4, AVI, TS, MOV, FLV, 3GP)
- Попробуйте другой файл
- Проверьте свободное место на устройстве

### Медленная загрузка

**Проблема:** Долго скачивается видео

**Решение:**
- Проверьте скорость интернета
- Telegram может ограничивать скорость
- Попробуйте файлы меньшего размера
